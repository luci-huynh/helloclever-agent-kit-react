# Core Rules — Frontend React

> @helloclever/agent-kit-react · core rules v0.1
> Applies to every React frontend project. Project-specific information (stack, structure, commands, reference files, overrides) lives in `.agent-kit/project.md`.

## How to read these rules

- **MUST**: mandatory. Any violation must be fixed before reporting the task as done.
- **SHOULD**: follow by default. If you don't, state why in your summary.
- **ASK FIRST**: stop and ask the user before doing it.
- Every rule has a code `R<section>.<number>` so `project.md` can override it precisely.
- When `project.md` conflicts with this file on conventions (structure, libraries, naming), follow `project.md`. Rules in **section 6 (Security & data)** and **section 8 (Definition of Done)** cannot be overridden.
