# Core Rules — Frontend React

> @helloclever/agent-kit-react · core rules v0.1
> Áp dụng cho mọi project FE React. Thông tin riêng của project (stack, cấu trúc, lệnh chạy, file mẫu, override) nằm trong `.agent-kit/project.md`.

## Cách đọc

- **MUST**: bắt buộc. Vi phạm thì phải sửa trước khi báo hoàn thành.
- **SHOULD**: mặc định làm theo. Nếu không theo, nêu lý do trong phần tóm tắt.
- **ASK FIRST**: dừng lại và hỏi người dùng trước khi làm.
- Mỗi rule có mã dạng `R<phần>.<số>` để `project.md` có thể override chính xác.
- Khi `project.md` mâu thuẫn với file này về convention (cấu trúc, thư viện, cách đặt tên), làm theo `project.md`. Các rule ở **phần 6 (Bảo mật & dữ liệu)** và **phần 8 (Definition of Done)** không bị override.
