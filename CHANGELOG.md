# Changelog

Theo [Semantic Versioning](https://semver.org/):
- **patch**: sửa câu chữ, làm rõ rule, không đổi hành vi AI.
- **minor**: thêm rule, skill, workflow mới.
- **major**: thay đổi khiến AI hành xử khác đáng kể, đổi cấu trúc file trong project.
