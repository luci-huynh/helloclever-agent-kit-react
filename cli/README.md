# CLI (làm sau)

Dự kiến:
- `agent-kit init` — copy templates, ghép core rules theo `config.json`, hỏi có chạy AI tạo `project.md` không.
- `agent-kit sync` — cập nhật core rules, skills, workflows khi nâng version. Không đụng vào `project.md`.
- `agent-kit profile --refresh` — quét lại project, đề xuất diff cho `project.md`.

Giai đoạn pilot: cài thủ công theo README ở gốc repo.
