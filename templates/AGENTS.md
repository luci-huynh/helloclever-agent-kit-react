# AI Agent Instructions

<!-- Tạo bởi @helloclever/agent-kit-react. Không sửa core rules trong project; tuỳ chỉnh trong .agent-kit/project.md -->

Trước khi làm bất kỳ task nào trong repo này, đọc và tuân theo hai file sau:

1. `.agent-kit/core-rules.md` — quy tắc chung cho mọi project FE React của Hello Clever.
2. `.agent-kit/project.md` — thông tin thực tế và các override riêng của project này.

Khi hai file mâu thuẫn về convention, `project.md` được ưu tiên, trừ các rule được đánh dấu "không bị override" trong core rules.
